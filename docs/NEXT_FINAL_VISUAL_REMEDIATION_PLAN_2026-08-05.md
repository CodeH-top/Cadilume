# 最终视觉与资料详情追加整改计划（2026-08-05）

本计划承接 `NEXT_LIBRARY_AND_ALBUM_REMEDIATION_PLAN_2026-08-05.md` 与
`NEXT_PLAYER_PANEL_AND_THEME_POLISH_PLAN_2026-08-05.md`，只处理用户最新明确的
视觉与信息层级更正。若与此前同类描述冲突，以本文为准。

## 目标与边界

- 继续复用唯一的 `pnpm tauri dev` 开发链，通过 HMR 验收；不重启或另起原生实例。
- 不改变 Plex/PMS 数据读取、播放队列语义、歌词解析、歌单 Rust/Tauri 边界或路由缓存。
- tooltip 必须是控件中心锚定的应用内可见提示，同时保留 `aria-label`；不只依赖原生
  `title` 作为唯一反馈。
- 不截图；用 DOM、computed style、可访问名称、控制台和测试验证。

## R1：标题栏动作归位

- 收回展开播放器的按钮保持标题栏左侧。
- 黑胶/封面模式开关移动到标题栏右侧动作组，紧挨主题切换按钮的左边；主题按钮和连接状态
  仍按“主题、连接”顺序位于最右侧。

## R2：列表文字与头像对比

- 歌曲标题与“共 X 首歌曲”采用底部对齐，计数不再在视觉上高于标题基线。
- 歌手列表的圆形头像在暗色主题增加低亮边界、深层投影和轻微反差外光；浅色主题保持原有克制
  的描边，避免生成白边。

## R3：专辑层级与操作

- 专辑名称恢复为详情主标题；歌手缩小后放在其下，与年份合成为 `歌手 · 年份`。
- 专辑“随机播放”改为纯图标按钮，与“添加到歌单”并列；两个按钮均有中文 tooltip。

## R4：纯图标 tooltip 审核

- 通用 `IconButton`、主题、底部播放/静音、展开播放器控制、回到顶部、创建歌单和通知关闭
  均输出可见 tooltip；禁用的无歌词按钮继续维持已有专用提示，不产生重复气泡。
- tooltip 默认显示于控制上方；顶部标题栏翻转到下方，均以按钮中心定位且支持 keyboard focus。

## R5：折角唱臂与真实落针几何

- 用早期折角唱臂作为结构基线：轴座位于唱片右上外侧，折角臂从轴座向外圈延伸。
- 唱头与针头固定在折角末端；目标落点位于唱片外圈有效唱纹，不能再指向中心标签或贴在最外缘。
- 所有机械部件以同一个舞台百分比坐标缩放，深浅主题只改变金属明暗，不改变物理位置。

## R6：歌词浮层层级、当前行强调与真实同步回归

- 普通歌词浮层必须低于展开播放器；从底部播放器打开展开播放器时，先关闭普通歌词浮层，
  展开播放器右侧自带的歌词区域继续默认显示。
- 普通歌词的当前行从基础 `17px` 提升到 `20px`，其他行和第二语言文本维持原尺寸，增强当前
  播放位置辨识度且不使用会遮挡相邻歌词的缩放变换。
- 周杰伦《完美主义》列为真实 PMS 歌词同步专项回归样本。后续需在相同歌词源下检查开头、
  中段、结尾、seek 与暂停恢复；完成采样前不加入猜测性的固定 delay，也不宣称同步问题闭环。

## R7：播放失败提示尺寸与错误预留

- 播放失败提示内的两个操作按钮统一为紧凑桌面尺寸，清除主按钮继承的外边距，避免 flex 行被
  撑高后把右侧按钮拉伸；右侧操作名称缩为“播放设置”。
- 周杰伦《天地一斗》出现 `MediaError code 4`，自动源、320、256、192 kbps 均失败。按用户
  决定，本轮只登记真实回归样本，不修改代理、转码或回退逻辑；后续专项需补齐脱敏的 HTTP
  状态、Content-Type、连接类型和转码端点诊断后再确认根因。
