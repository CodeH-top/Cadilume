## 1. 计划固化与现状基线确认

### 问题澄清

- “普通歌词弹窗”指底部播放器歌词按钮控制的根部浮层，而不是歌词正文的字号。
- 用户要求它的**位置、尺寸、进出方式**与播放队列一致；歌词仍然不加 scrim，也不新增
  关闭按钮或 Escape 关闭途径。
- “右上角主题动画”是从主题按钮所在位置扩散显示新主题的圆形揭示，而不是整页淡出。

### 基线

- 歌词文字恢复为主行 `17px / 700 / 1.42`、次行 `13px / 550`。
- 播放队列的右侧宽度、固定边距、无 scrim 与 `queue-panel-in/out` 是歌词浮层的几何/动效
  参考；二者保持根状态互斥。
- 展开播放器的右侧歌词是默认内容区；“不显示歌词按钮”只表示展开播放器底部不重复放置
  歌词开关，不能删除这块歌词内容。
- 唱臂与唱头取 `HEAD^^:src/NowPlayingView.css`，轴座取
  `HEAD^:src/NowPlayingView.css`，避免按印象重绘。

### 验收

- 文档能作为本轮唯一的增量执行入口，所有后续回填写入本文。

## 2. 普通歌词字号与右侧队列式浮层

### 修改

1. 在 `src/App.css` 恢复 `.lyric-line` 与翻译行的原始字体尺寸、字重和行高。
2. 将 `.lyrics-panel-layer`、`.lyrics-panel` 的固定定位、宽度、高度、圆角、阴影和动画
   对齐 `.queue-panel-layer`、`.queue-panel`，但保留歌词层原有的 `pointer-events` 边界，
   不引入遮罩层点击关闭。
3. 歌词面板进入/退出复用队列的横向进出节奏。打开队列时继续先关闭歌词，确保任一时刻
   只有一个右侧浮层参与布局和绘制。
4. 保留歌词滚动、逐行点击 seek、无歌词状态及无障碍语义，不让几何调整改变内容行为。

### 验收

- 主歌词行 computed font-size 为 `17px`，翻译行为 `13px`。
- 歌词和队列面板的边缘、宽高及水平动画计算值一致；歌词没有额外 scrim。
- 从歌词切到队列时先关闭歌词，再显示队列，控制台无错误。

## 3. 右上角主题揭示动画与标题栏 hover 清理

### 修改

1. 恢复 `ThemeCycleButton` 传递点击中心坐标，并让 `playAppearanceReveal()` 接收该 origin。
2. 新主题先同步应用到 live tree，旧主题 snapshot 保持在上方；snapshot 从覆盖整窗的圆形
   裁切，动画收缩到按钮 origin，从而让新主题从右上角向外揭示。
3. 快照在挂载后复制各滚动容器位置与媒体几何，保持已有的双帧稳定和图片 decode 等待；
   圆形裁剪仅限 snapshot，动画结束立即移除。
4. 移除顶部账户块的鼠标 hover 高亮，保留键盘 `:focus-visible` 提示；主题、关闭、播放和
   连接等实际操作继续保留 hover/focus 反馈。

### 验收

- 点击右上角主题按钮可见以按钮为中心的新主题揭示，reduced-motion 下直接切换。
- 页面滚动到任意位置时，过渡不从页面顶部闪现，媒体尺寸和裁切稳定。
- 标题栏空白拖拽区域 hover 时没有伪按钮状态。

## 4. 黑胶、固定底座与唱臂组合

### 修改

1. 普通播放器 `.mini-vinyl` 保持无可见描边；暗色模式补充反向色的轻微外发光、可辨的
   纹理和中心层次，不制造浅色模式下明显白边。
2. 展开播放器 `.now-playing-record-stage::before` 改为固定的浅色物理底座配色，不读取
   深浅主题变量，保证两种主题下底座观感一致。
3. 轴座 CSS 精确恢复为 `HEAD^` 的版本；唱臂、唱头与唱针精确恢复为 `HEAD^^` 的版本，
   并保留现有的旋转锚点和响应式变量。

### 验收

- 暗色模式的底部小黑胶不再淹没在播放器底色中，浅色模式也没有外框。
- 展开播放器底座在两种主题下取相同色值。
- 轴座、唱臂和唱头来自指定历史基线，且尺寸缩放时仍共用同一 pivot。

## 5. 展开播放器标题栏与默认歌词

### 修改

1. 为 `NowPlayingView` 增加右上角扩展动作 slot，避免在展开播放器内复制主题和连接逻辑。
2. 由 `App.tsx` 传入既有 `ThemeCycleButton` 和 `ConnectionIndicator`；二者沿用已有的
   tooltip、无障碍文案和连接语义。
3. 黑胶 / 封面模式开关与收回按钮一起留在标题栏左侧；主题与连接状态只出现在右侧，二者
   不互相挤压原生拖拽区。
4. 展开播放器内容区固定保留右侧歌词列，复用同一歌词状态、逐行 seek 与自动跟随逻辑；无
   歌词、加载和错误状态在右列说明，展开播放器底部不重复渲染歌词按钮。

### 验收

- 展开播放器右上角同时显示主题切换和当前连接形式。
- 黑胶 / 封面开关在标题栏左侧，右侧歌词始终存在；即使暂无歌词也显示相应空状态，底部控制
  区没有歌词按钮。
- 两项实际可操作/可聚焦，tooltip 锚定在各自控件中心，关闭展开播放器后主窗口状态不变。
