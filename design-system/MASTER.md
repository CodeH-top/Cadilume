# Cadilume Design System

## 视觉方向

- Cadilume 是桌面资料库优先的音乐客户端。信息密度、内容优先级和播放控制层级贴近原生 Plex/Plexamp 的桌面体验，但产品标识、组件、代码、图标与资产必须保持 Cadilume clean-room 实现。
- 深色与浅色是同等完整的双主题，不把浅色主题当作深色主题的简单反色。两套主题使用同一套语义 token、信息结构与交互状态。
- 视觉去 AI 化只移除三类表达：标题上方无信息价值的英文装饰标签、详情与状态页的大面积无效留白、夸张或弹跳式缩放。
- 已建立的渐变、玻璃、光晕、阴影、圆角、胶囊和唱片视觉继续保留；它们用于建立层级和音乐氛围，不得堆叠成抢夺内容注意力的装饰。
- 页面标题直接使用清楚的中文层级。产品名、音频格式缩写、协议名称和设备名称可按其正式写法显示，不额外添加全大写英文氛围文案。
- 保留系统原生标题栏，不自绘 macOS 或 Windows 窗口控件。项目内功能图标统一使用 Lucide 线性图标；品牌标记与应用图标只使用 Cadilume 自有的暖橙箭头语言。

## 语义 Token

| 语义 | 深色 | 浅色 |
| --- | --- | --- |
| Background | `#101112` | `#F7F5F2` |
| Sidebar | `#141516` | `#EEECE8` |
| Panel | `#191B1C` | `#FFFFFF` |
| Raised panel | `#202223` | `#E8E5E0` |
| Text | `#F4F4F1` | `#202120` |
| Muted | `#9B9E9F` | `#696C6B` |
| Accent | `#F0A15D` | `#B95D19` |
| Error / Danger | `#EE7B73` | `#B94841` |
| Range track | `#3A3D3E` | `#C5C1BA` |

- 间距以 8px 为基础，允许 4px 半步用于紧凑控件和精细对齐。
- 常用圆角为 6/8/10/12px；弹窗与强调表面可使用 14/16/20px；胶囊和开关使用全圆角。
- 字体使用系统 UI：`-apple-system`、`BlinkMacSystemFont`、`SF Pro Text`、`Segoe UI`、`Noto Sans SC` fallback。
- 应用内所有可见文字的计算字号不得低于 12px；12px 只用于次要信息、时间、状态与说明，正文和主要操作优先使用 13–15px。
- 强调色用于主播放、选中态、进度、焦点和少量品牌光晕；危险色仅用于错误和“退出账号”等不可逆或身份切换操作。

## 窗口与布局

- 默认窗口尺寸与最小窗口尺寸均为 `1280×820`，用户不可继续缩小；该尺寸是所有页面和状态的首要验收基线。
- 主壳使用“侧栏 + 内容区 + 92px 固定底部播放器”。最小窗口使用 218px 侧栏，只有浏览器调试到更窄断点时才进入紧凑回退布局。
- 底部播放器始终保留当前曲目、播放控制、进度、歌词/队列/输出入口和独立音量；窗口高度变化不得隐藏音量或让播放器离开底边。
- 主内容采用紧凑但可扫读的资料库布局。页面标题、详情封面、主要动作与曲目列表之间不得用空白制造舞台感；空白只负责分组和阅读节奏。
- 专辑和歌手使用自适应卡片网格，歌曲使用可扫读表格。歌手/专辑右侧保留 A–Z/# 索引并服从 PMS `titleSort` 顺序；详情封面可保留柔和阴影，圆形歌手头像与方形专辑封面保持各自语义。
- 右侧队列和歌词面板常规宽度为 350px；最小尺寸下使用 330px 的主窗口内覆盖层，不挤坏资料库，也不遮挡固定底部播放器。
- 展开播放器是覆盖整个应用视口的主窗口内模态层，维持固定的标题、内容和控制三段骨架。曲目、封面或歌词变化不得推动整层上下位移。
- 登录与启动状态应有足够大的品牌锚点、清晰进度和紧凑内容卡，不使用微小 Loading 孤立在空白窗口中，也不以大面积留白制造氛围。

## 侧栏与设置入口

- 侧栏只保留品牌、主导航、常驻歌单区和底部账号卡，不显示服务器或媒体库来源选择器。
- 服务器与媒体库选择、资料同步等来源管理统一进入设置。
- 歌单区位于主导航下方、账号卡上方，显示普通、智能和只读音频歌单。当前歌单、hover 与键盘 focus 必须在双主题下清楚可辨。
- 歌单列表是侧栏内唯一的纵向滚动区：使用 `min-height: 0`、透明轨道和约 5px 的低对比圆角 thumb；hover 或拖动时适度增强。品牌、主导航和账号卡不得随歌单滚动。
- 左下角账号卡是唯一设置入口。删除独立设置按钮和无功能的更多菜单；账号卡在设置页显示明确选中态。
- 设置页内提供服务器、媒体库、主题、关闭行为、缓存和“同步资料”等配置。“退出账号”使用危险色；设置页不提供退出应用操作。

## 内容与媒体呈现

- 封面进入可视区域前预取合适尺寸，避免请求无必要的原图和滚动闪烁。封面加载失败使用项目内 Music 图标占位，不显示破图或外部占位图。
- 封面由 Rust 鉴权、缓存后通过受控资源地址提供；组件不得拼接、显示或持久化带 Plex token 的图片地址。
- 专辑与歌手卡片 hover/focus 不叠加播放三角。常态使用柔和深度阴影，交互时允许主题色边框、光晕、最多约 2px 的轻位移和约 `1.01` 的细微缩放，不得引发布局位移。
- 胶囊用于连接状态、音频格式、能力或短标签，不用胶囊包裹每一段普通信息。
- 连接状态标签只表达拓扑：本地直连、远程直连或 Plex Relay；它与音频是否直放是两个维度。Cadilume 的 `127.0.0.1` 地址只是隐藏凭据的安全代理，不得被标成“本地连接”。
- 唱片、波形、渐变和背景光晕可用于登录、启动和展开播放器，但必须服从曲目、歌词与控制器的信息层级。
- 播放失败使用应用根层的全局提醒，默认只给出清楚的结果与下一步；技术诊断折叠显示，不在播放器底栏塞入难以发现的小字。

## 播放器与歌词

- 底部主播放键使用主题色圆形按钮，播放三角允许 1px 光学校正；hover、focus、active 与 disabled 状态均需明确，且不能改变按钮占位。
- 进度条和音量条始终显示“已完成/当前值”的主题色填充与“剩余值”的轨道色；thumb 可在 hover/focus 时增强，但静止状态仍能看出进度。
- 播放状态若显示“直放”，表示音频未转码；需要转换时由 PMS 处理，Cadilume 本地代理不承担转码，也不得把安全代理描述成转码器。
- 随机、循环等状态按钮在选中后保持主题色和强调背景；选中态 hover 不得退回普通白色或丢失选中反馈。
- 底栏歌词按钮只打开主窗口右侧歌词面板；展开播放器不重复显示歌词，也不创建独立浮动歌词窗口。确认当前歌曲没有非空歌词时按钮禁用。
- 时间轴歌词按活动媒体播放进度高亮并自动滚动；有时间戳的歌词可点击跳转。保留 PMS 毫秒边界，不添加未经多曲验证的固定延迟；纯文本歌词保持完整可读，不伪造时间轴。
- 歌词切换使用 180–200ms 的颜色、透明度、轻位移和标记渐变；歌词列表独立滚动，任何自动定位都不得滚动播放器外层或改变固定骨架坐标。

## AirPlay 与平台输出

- macOS 底栏 AirPlay 按钮单击后直接调用当前媒体元素的系统 AirPlay 设备选择器，不先打开 Cadilume 中间面板。
- 当前没有可播放曲目，或系统选择器不可用时，提供明确且可执行的状态提示；不得暗示 Cadilume 已掌控系统音频路由。
- Windows 和其他平台根据实际可用能力提供输出设备入口或系统设置降级路径，不复用 macOS AirPlay 文案，也不展示不可执行的设备操作。
- 输出能力属于 best-effort 平台集成；文案不得宣称严格 gapless、完整系统媒体控制或已覆盖所有 USB、蓝牙与 HDMI 设备。

## 交互状态与动效

| 状态 | 基线 |
| --- | --- |
| Hover | 通过颜色、背景、边框、透明度、阴影或极轻位移增强可发现性，不制造布局抖动。 |
| Focus | 所有键盘可操作控件使用 2px 暖橙焦点轮廓与合理 offset；焦点不得只依赖 hover。 |
| Active / Selected | 使用主题色、强调背景、边框或内侧标记持续表达；hover 后仍保持选中语义。 |
| Pressed | 允许亮度或阴影短暂收紧，禁止弹跳和夸张缩放。 |
| Disabled | 降低对比度并使用不可用光标；不响应 hover，不与未选中态混淆。 |
| Busy / Loading | 保持布局和按钮尺寸，显示 spinner、`disabled` 与 `aria-busy`；异步完成前不得重复触发。 |

- 常规过渡为 150–200ms，优先使用 ease-out；不对布局尺寸和大范围位置做装饰动画。
- 遵守 `prefers-reduced-motion: reduce`：关闭非必要动画、平滑滚动、歌词位移与卡片缩放，功能状态仍通过颜色、边框和文字表达。
- 登录按钮从打开授权页到账号资料重载完成始终保持 busy/disabled，不允许成功返回后再次触发登录；界面不显示原始授权字符串。
- 应用根节点默认禁止文本选择；输入框、文本域、可编辑内容和诊断代码恢复文本选择能力。

## 可访问性

- 所有有意义图片提供替代文字，纯装饰图形对辅助技术隐藏。
- 所有图标按钮提供准确的 `aria-label` 与 `title`；不能用图标形状代替名称。
- 资料库导航、主要内容、歌单、队列、歌词和播放器具备对应语义区域，并提供“跳到主要内容”链接。
- 动态状态使用 `role="status"`，播放失败等需要立即注意的终止态使用 `role="alert"`；同一错误只保留一个主要提醒。
- 对话框进入时移动焦点、限制焦点范围并支持 Escape 关闭；关闭后把焦点还给触发控件。
- `⌘/Ctrl + K` 聚焦搜索，Space 播放/暂停；系统媒体键在平台能力允许时由 Media Session 处理。
- 深浅主题均需检查文本、图标、焦点、禁用态、危险态、滚动条和主题色阴影的对比度，不用纯颜色作为唯一状态线索。

## Clean-room 边界

- Plex、Plexamp 与 PMS 仅用于描述第三方服务、协议兼容和行为参考，不作为 Cadilume 产品身份。
- 不复制第三方源代码、私有原生模块、品牌资产、图标、标识符、遥测密钥或许可受限二进制。
- 任何界面优化都必须继续服从服务器 ACL、订阅能力边界与凭据安全；视觉上的“可播放”或“可写入”不得绕过实际授权。
